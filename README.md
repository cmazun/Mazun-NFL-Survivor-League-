# Mazun NFL Survivor League

A mobile-friendly static dashboard for Ryan, Corey, Tyler, and Dad. Includes the handwritten picks, results, standings, an 18-week tracker, team reuse prevention, and JSON backup/import.

## Publish
In repository **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.

## Important
Pick changes are stored in browser localStorage and **do not synchronize** across devices. Export backups from Rules & Backup. No automatic NFL score feed is connected.

## Data review
Initial entries are transcribed from a photo. Verify all names, picks, and outcomes. Dad's Houston pick is marked pending.
